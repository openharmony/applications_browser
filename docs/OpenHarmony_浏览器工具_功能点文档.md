## 3. 核心需求摘要（提炼）

| 主题 | 内容概要 |
|------|----------|
| 浏览与导航 | 多标签；前进/后退/刷新/主页；Web 内容区基于系统原生 Web 组件。 |
| 地址与检索 | URL 访问、默认搜索引擎检索、地址栏历史联想下拉。 |
| 书签 | 书签栏展示与跳转；收藏按钮添加/修改/移除；书签管理（文件夹、导入、导出、「网址/文件夹」更多操作）；书签栏空白处与书签项右键。 |
| 下载 | 导航栏入口与菜单进入下载管理；列表、任务展示、清空、删除、「在文件夹中显示」。 |
| 菜单与页面操作 | 主菜单及子菜单项（含新标签/新窗口/无痕、缩放、查找、打印、桌面快捷、另存为、UA）；缩放比例可调；页内查找。 |
| 设置与安全 | 搜索引擎管理与默认引擎；浏览/下载设置；网站数据与权限展示与管理；起始页；安全浏览；历史记录；清除浏览数据；默认浏览器入口；代理；关于。 |
| 上下文菜单 | 地址栏、标签、网页空白/图片/链接/选中文本等场景的右键菜单。 |
| 窗口 | 系统窗口缩放（按钮与拖拽）、最小化；新窗口与无痕窗口入口（语义见 PRD）。 |
| 工程文档类功能点 | 设计说明书、开源 Readme（作为交付物纳入基线）。 |

## 4. 边界需求（严格对齐基线）

- **纳入范围**：与 `浏览器需求文档.xlsx` 所列一级 / 二级 / 细分功能点 **逐项等价**，不增删条目。
- **技术边界**：实现形态为 **纯 ArkTS + ArkUI、Stage 模型、系统原生 Web 组件**，无第三方浏览内核与第三方业务 SDK。
- **明确不包含**：账号与云端同步、扩展插件生态、内置开发者调试套件、AI 增强浏览、内核级自定义等非基线条目（详见 PRD「范围外」）。
- **系统能力依赖**：打印、桌面快捷方式、默认浏览器、代理等受 OpenHarmony 6.0+ / API 23 及具体设备策略约束；无法实现时需降级提示，不得虚构能力。

## 5. 异常与负面场景（概要）

| 场景 | 期望概要 |
|------|----------|
| 地址非法或不可解析 | 提示用户或按「搜索」路径处理（与 PRD 8.5.1 一致）。 |
| 页面加载失败 | 单页失败不拖垮应用；宜提供错误态与重试（见 PRD 非功能）。 |
| 下载失败 / 存储不可用 | 状态可追溯；允许删除记录或按产品设计重试；权限失败须明示原因。 |
| 存储读写失败 | 不回写错误数据；界面状态与持久层一致，必要时 Toast / 对话框说明。 |
| 无痕会话 | 不写入常规历史等持久行为（语义见 PRD 无痕条款）。 |
| 清除浏览数据 | 按所选类别清除后立即生效；不可恢复的破坏性操作需二次确认（细则见后续设计与实现）。 |
| 系统 API 不可用 | 禁用入口或降级提示，不写死成功路径。 |
