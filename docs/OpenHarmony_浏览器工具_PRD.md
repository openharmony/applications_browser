# OpenHarmony 浏览器工具 产品需求文档（PRD）

## 1. 文档信息

- **文档名称**：OpenHarmony 浏览器工具 产品需求文档（PRD）
- **版本**：V1.1（重新生成）
- **状态**：正式版（用于评审/立项/开发）
- **归档路径**：`OpenHarmonyBrowser/OpenHarmony_浏览器工具_PRD.md`
- **关联功能点文档**：`OpenHarmonyBrowser/OpenHarmony_浏览器工具_功能点文档.md`
- **适配范围**：`OpenHarmony_standard_p7885_20260414`、OpenHarmony 6.0+、API Level 23
- **需求基线来源**：与本仓库同级路径 `浏览器需求文档.xlsx`（条目完整性以该表为准；本文与之逐项对齐）

## 2. 编制目的

本文档定义浏览器工具的 **产品目标、功能范围、业务规则、交互约束与验收标准**，作为需求评审、开发实现、测试验收与归档的统一依据。

## 3. 术语与定义

- **浏览器工具**：运行于 OpenHarmony 标准系统上的桌面浏览器应用。
- **无痕模式**：独立会话窗口，不写入常规历史与常规 Cookie 持久数据。
- **标签页**：单窗口内的多页面容器。
- **书签**：用户保存的网页入口，可组织为文件夹。
- **下载任务**：由浏览行为触发的文件下载记录与状态对象。
- **UA 标识**：浏览器对外声明的 User-Agent 字符串。

## 4. 产品背景与目标

### 4.1 背景

在 OpenHarmony 标准系统环境中，需要一款满足基础浏览、收藏、下载、设置与内容操作能力的浏览器工具，支持桌面场景下的高频浏览行为与配置管理。

### 4.2 产品目标

- 覆盖需求基线中全部功能点，确保可用、可测、可交付。
- 提供符合 OpenHarmony 原生交互与系统能力边界的浏览器体验。
- 形成规范化需求资产，直接支撑后续设计、开发、测试和验收。

## 5. 产品范围

### 5.1 范围内（严格纳入）

严格纳入 `浏览器需求文档.xlsx` 全部一级/二级/细分功能点（见第 9 章及《OpenHarmony_浏览器工具_功能点文档.md》）。

### 5.2 范围外（严格排除）

以下能力不在本次需求基线内：

- 账号体系、云同步、跨端同步
- 浏览器扩展插件市场
- 开发者工具（调试面板、网络抓包）
- AI 对话、摘要、翻译增强功能
- 多进程沙箱策略定制以外的系统内核改造

## 6. 用户角色与核心场景

### 6.1 用户角色

- **普通用户**：日常浏览、搜索、收藏、下载、设置调整。
- **管理用户**（同一产品角色内）：使用书签管理、下载管理、站点权限配置。

### 6.2 核心场景

- 快速访问：URL 直达 + 搜索 + 地址栏历史提示。
- 多任务浏览：多标签页并行打开、切换、关闭。
- 内容沉淀：收藏网址、管理书签、导入导出。
- 文件获取：发起下载、查看进度、管理历史任务。
- 安全与隐私：无痕窗口、安全浏览、清除浏览数据。
- 页面操作：缩放、页内查找、打印、另存为、添加至桌面。

## 7. 全局产品规则

### 7.1 系统兼容与技术约束

- 标准系统分支：`OpenHarmony_standard_p7885_20260414`。
- 系统版本：OpenHarmony 6.0+。
- API Level：23。
- UI 与交互需遵循 OpenHarmony / HarmonyOS 设计指南中与桌面浏览器形态相容的原生控件与窗口语义。
- **工程实现约束**：纯 ArkTS + ArkUI、**Stage 模型**、**系统原生 Web 组件**渲染网页内容；**不引入第三方浏览内核、不接入第三方业务 SDK**。
- SDK / DevEco 编译指引：`OHOS-SDK` 默认路径 `C:\Users\Administrator\AppData\Local\OpenHarmony\Sdk`；DevEco Studio `C:\Program Files\Huawei\DevEco Studio\bin`（以本机安装为准）。

### 7.2 数据管理规则

- 常规模式下，历史、下载记录、书签、设置等按本地持久化保存。
- 无痕窗口关闭后，临时浏览会话数据不进入常规历史。
- 用户主动「清除浏览数据」后，对应数据应按选项立即删除并生效。

### 7.3 交互一致性规则

- 同类入口行为一致（菜单、右键、按钮触发结果一致）。
- 多处可触达同一能力时，统一进入同一功能页面或同一处理流程（例如下载管理、历史记录）。

## 8. 功能需求（按模块）

### 8.1 UX

#### 8.1.1 UX 设计

- **功能点**：UX 设计
- **需求说明**：浏览器整体视觉、布局、交互反馈符合桌面浏览器习惯及 OpenHarmony 原生设计规范。
- **验收标准**：
  - 页面结构清晰，导航栏、地址栏、标签栏、书签栏、内容区层次明确。
  - 常用操作具备可见反馈（加载、禁用态、成功/失败提示）。

### 8.2 文档

#### 8.2.1 文档设计

- **功能点**：设计说明书
- **需求说明**：形成完整设计说明书，支撑研发与评审。
- **验收标准**：设计文档结构完整、可追踪至需求条目。

#### 8.2.2 开源文档

- **功能点**：开源 Readme
- **需求说明**：提供可用于开源发布的项目说明文档。
- **验收标准**：包含编译运行、目录说明、能力列表、许可证信息。

### 8.3 窗口管理

#### 8.3.1 窗口缩放

- **功能点**：缩放按钮、手动调整
- **需求说明**：窗口支持标准缩放按钮与手动拖拽调整尺寸。
- **验收标准**：可通过窗口控件及边框拖拽改变窗口尺寸，内容区自适应。

#### 8.3.2 窗口最小化

- **功能点**：窗口最小化
- **需求说明**：支持窗口最小化到系统任务区。
- **验收标准**：点击最小化后窗口隐藏，任务区可恢复。

### 8.4 导航栏（*）

#### 8.4.1 前进

- **需求说明**：在可前进历史存在时可执行前进。
- **验收标准**：无前进历史时按钮置灰；有历史时可跳转。

#### 8.4.2 后退

- **需求说明**：在可后退历史存在时可执行后退。
- **验收标准**：无后退历史时按钮置灰；有历史时可跳转。

#### 8.4.3 刷新

- **需求说明**：支持当前页面刷新。
- **验收标准**：触发后重载当前网页，加载状态可见。

#### 8.4.4 主页

- **需求说明**：支持一键返回主页。
- **验收标准**：点击后进入已配置主页。

#### 8.4.5 下载按钮

- **需求说明**：导航栏提供下载管理快捷入口。
- **验收标准**：点击后进入下载管理页面。

### 8.5 地址栏（*）

#### 8.5.1 访问 URL

- **需求说明**：输入完整/可识别网址并访问。
- **验收标准**：合法 URL 可正常打开；非法输入给出提示或按搜索处理。

#### 8.5.2 搜索

- **需求说明**：输入非 URL 文本可通过默认搜索引擎检索。
- **验收标准**：生成搜索请求并展示结果页。

#### 8.5.3 地址栏下拉框

- **功能点**：历史记录显示
- **需求说明**：输入时展示历史匹配项。
- **验收标准**：可展示并点击历史项快速访问。

#### 8.5.4 地址栏右键

- **需求说明**：地址栏支持右键菜单操作。
- **验收标准**：右键菜单可正常弹出并执行对应动作。

#### 8.5.5 书签「收藏」按钮

- **功能点**：添加/修改/移除书签
- **需求说明**：可将当前页加入书签、更新信息或取消收藏。
- **验收标准**：操作后书签栏/书签管理器状态实时更新。

### 8.6 标签栏

#### 8.6.1 打开新标签页

- **验收标准**：新标签可创建、激活并可继续访问页面。

#### 8.6.2 标签右键菜单显示

#### 8.6.3 关闭标签

- **需求说明**：支持关闭当前或指定标签。
- **验收标准**：标签关闭后焦点按预期切换。

### 8.7 书签栏

#### 8.7.1 展示书签

- **需求说明**：在书签栏展示书签及文件夹。
- **验收标准**：书签可见、可点击打开。

#### 8.7.2 编辑书签

#### 8.8.5 书签

- **功能点**：书签管理器

- **验收标准**：书签管理能力完整可用。

#### 8.8.6 历史记录

- **需求说明**：菜单可进入历史记录页面。
- **验收标准**：历史可按时间展示并可访问。

- **需求说明**：菜单可进入下载管理页面。
- **验收标准**：页面显示下载任务及管理操作。

- **需求说明**：支持页面缩放比例调整。
- **验收标准**：页面渲染按比例变化，比例状态可识别。

#### 8.8.9 页内查找

- **需求说明**：支持当前页面关键字查找。
- **验收标准**：匹配结果高亮并可跳转上一条/下一条。

#### 8.8.10 打印

- **功能点**：打印当前网页内容
- **需求说明**：支持触发打印流程。

#### 8.8.11 添加至桌面（*）

- **功能点**：创建当前页面快捷打开方式
- **需求说明**：将页面创建为桌面快捷方式。
- **验收标准**：桌面成功生成可点击入口并可打开目标页面。

- **需求说明**：支持将当前网页内容保存到本地目录。

- **功能点**：手动切换浏览器支持的 UA 标识
- **需求说明**：支持在预设 UA 列表中切换。
- **验收标准**：切换后新请求按所选 UA 发起。

#### 8.9.1 搜索引擎

- **功能点**：搜索引擎设置、管理搜索引擎
- **需求说明**：支持默认搜索引擎设置及管理。
- **验收标准**：可新增/编辑/删除（受保护项除外）并设置默认。

#### 8.9.2 浏览设置

- **需求说明**：提供浏览相关通用开关/偏好项。
- **验收标准**：配置项可保存并即时或重启后生效（按项定义）。

#### 8.9.3 下载设置

- **需求说明**：提供下载路径及下载行为配置。

## 10. 非功能需求

### 10.1 性能

- 应用冷启动、页面切换、标签切换满足桌面可用性要求。
- 常见操作（新建标签、切换标签、打开菜单）需保持流畅。

### 10.2 稳定性

- 单页面加载失败不影响应用主体可用。
- 下载任务异常（网络中断、权限不足）应提示并可恢复或重试。

### 10.3 安全与隐私

- 无痕窗口与常规窗口会话隔离。
- 站点权限修改受控且可回溯。
- 清除浏览数据后确保数据不可见。

### 10.4 可维护性

- 功能模块边界清晰，便于后续迭代。
- 关键行为具备日志与错误码，支持问题定位。

## 11. 验收总则

- **覆盖性**：`浏览器需求文档.xlsx` 全部功能点均有实现与测试项。
- **一致性**：PRD、设计、实现、测试四者条目可双向追踪。
- **合规性**：适配范围严格限定于 OpenHarmony 6.0+、API 23、指定标准分支。
